# KariArt Raporty

Wewnętrzna aplikacja KariArt sp. z o.o. do przygotowywania
tygodniowych raportów sprzedażowych.

Odczytuje zamówienia, oferty i opłaty z własnego konta Allegro.
Nie zmienia ofert ani zamówień.

Wersja: 1.0.0
Kontakt: biuro@kariart.pl

Repozytorium zawiera wyłącznie opis aplikacji.
Dane sprzedażowe i klucze dostępowe nie są tutaj publikowane.
